# PROYECTA-IA — Capítulo III: Ingeniería del Proyecto

Primer chatbot del **CAPÍTULO III. INGENIERÍA DEL PROYECTO (MARCO PRÁCTICO)**.

## Alcance de este módulo

Este chatbot trabaja únicamente:

1. Párrafo introductorio del Capítulo III.
2. Definición general del sistema.
3. Identificación de subsistemas.
4. Arquitectura o diagrama general del sistema.
5. Descripción breve de cada subsistema.
6. Relación hardware – software – firmware.
7. Revisión integral de la entrada del Capítulo III.

**No desarrolla todavía los Objetivos Específicos.**

Los objetivos se solicitan únicamente para comprobar coherencia con la arquitectura general.

## Ejemplos gráficos incluidos

La página incluye tres diagramas didácticos en SVG:

- Control y automatización.
- Electromedicina.
- Telecomunicaciones.

Cada diagrama puede descargarse en formato SVG desde el navegador.

## Revisión de figura del estudiante

La página permite:

- cargar PNG/JPG/WEBP/SVG;
- previsualizar;
- comprobar resolución y requisitos básicos;
- usar una lista de verificación;
- copiar un prompt para realizar análisis visual profundo en ChatGPT junto con la imagen.
